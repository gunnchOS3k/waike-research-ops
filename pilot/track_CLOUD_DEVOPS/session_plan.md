# Session plan — CLOUD_DEVOPS

**Pilot status:** NOT RUN · design only

## Proposed pilot envelope

| Item | Plan |
|------|------|
| Format | 2–4 facilitated sessions (subset of full 10-week course) |
| Cohort size | 6–12 learners (TBD by campus) |
| Mode | Synthetic / local first |
| Full course claim | Forbidden — pilot is a slice |

## Candidate sessions (from real week titles)

- **Session focusing Week 1:** ForgeCloud — Linux permissions before the fancy YAML — lab `lab_linux_perms`
- **Session focusing Week 2:** Git on ForgeCloud — history you can roll back — lab `lab_git_state`
- **Session focusing Week 3:** Containers — Dockerfile that refuses :latest and root — lab `lab_dockerfile_lint`
- **Session focusing Week 4:** CI/CD gates — lint then test then upload, never ungated deploy — lab `lab_cicd_gate`

## Session skeleton (each meeting)

1. Safety / consent reminder (5m)
2. Objective + worked example (15m)
3. Guided lab (40–60m)
4. Artifact check / exit ticket (15m)
5. Issue log capture (10m)
