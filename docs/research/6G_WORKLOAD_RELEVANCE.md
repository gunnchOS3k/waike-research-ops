# 6G workload relevance — supporting education/ops

WAIKE is **not** an extra dissertation paper and **not** a RAN. It is a supporting education/ops workload whose measurable artifacts are packets, validators, and learner/instructor journeys.

## What can be measured here

| Characteristic | Where it shows up | What it is not |
|---|---|---|
| Package depth | 14 digital-RC `course.json` trees, lesson length floors, lab JSON validators | A 6G air-interface result |
| Lab honesty | Empty/`PASS` fail; reference submissions pass (`src/waike_course_ready/labs.py`) | Over-the-air measurement |
| Claim boundary | `WIRELESS_6G` forbids commercial standardized 6G; FSPL/NTN delay fixtures | Spectrum license or 3GPP product |
| Cross-repo apprenticeship map | `knowledge_maps/course_repo_map.yaml` → twin, SpectrumX, beam, NTN, edge-io | Those repos' RF claims |
| Privacy | No transcripts/grades/PII in git; anonymous completion checklist | An LMS |

## Networking / system characteristics (honest)

- **Digital compose / Device Lab** language in SOFTWARE_BUILDER and CLOUD_DEVOPS labs is local tooling, not a deployed 5G/6G core.
- **WIRELESS_6G** teaches FSPL, OFDM numerology intuition, 5G-Advanced *labels*, NTN light-time, gated AI-RAN *policy* on fixtures.
- System load from this repo is **content + Python validators + CI**, not UE/gNB traffic.

Sibling experimental repos remain the place for RAN/twin/NTN numbers. This repo trains people to read those artifacts without fabricating impact statistics.

## Non-claims

No University of Oulu / CWC / 6G Flagship affiliation. No carrier certification. No citywide educational impact.
