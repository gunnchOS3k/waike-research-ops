## Metrics

| Metric | Description |
|--------|-------------|
| Throughput | Data delivery rate for learning activities |
| Continuity | Uninterrupted service during sessions |
| Accessibility | Low-bandwidth alternatives, screen reader, captioning |
| Mobility | Handover between access points during movement |
| Handover | Seamless transition between Wi-Fi and cellular |
| Jitter | Variation in packet delay for real-time interactions |
| Local edge latency | Response time for on-device and near-device compute |
| Sync delay | Time to synchronize state across devices |
| Haptics latency | End-to-end delay for tactile feedback loops |
