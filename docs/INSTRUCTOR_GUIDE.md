# Instructor Guide

Consent-first classroom use; no surveillance claims.

**Start:** [`instructor_training/instructor_onboarding_path.md`](../instructor_training/instructor_onboarding_path.md).

Executable digital-RC packages (14 on disk under `curriculum/digital_rc/`, not 18 catalog IDs) each have `instructor/INSTRUCTOR_PACKET.md`, rubrics, and `answer_keys.json`. Learner ingest must not contain keys.

Do not commit transcripts, grades, or PII. Completion tracking is an anonymous artifact checklist (`schema/waike_completion_tracking.v1.json`).
