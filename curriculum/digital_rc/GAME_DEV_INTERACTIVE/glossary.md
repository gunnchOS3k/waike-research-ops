# Glossary — GAME DEV INTERACTIVE

Track: `GAME_DEV_INTERACTIVE`

## game loop
Update → simulate → render cycle running at a target tick/frame rate.

## delta time
Elapsed time between frames used for frame-rate independent motion.

## scene graph
Hierarchy of entities/transforms in a level.

## input mapping
Binding device inputs to gameplay actions.

## playtest note
Observed player behavior, not designer wishful thinking.

## asset license
Rights that allow redistribution of art/audio.

## HITL content
Human review before shipping content that depicts people/communities.

## accessibility mode
Options such as remappable inputs, captions, reduced motion.
