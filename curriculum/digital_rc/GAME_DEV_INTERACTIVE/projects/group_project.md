# Group project — Game Dev Interactive (Forge Arcade Studio)

## Brief
Build a **10-minute playable slice** with one core verb, one fail state, and accessibility notes. Roles: gameplay + content/ethics reviewer.

## Deliverables
1. Build artifact + controls card.
2. Playtest log (n≥3 peers) with observed vs inferred.
3. Asset license table.
4. Accessibility notes (remap, captions/reduced motion).

## Rubric anchors
Playability · Honesty of playtests · Licensing · Accessibility

## Explicit non-claims
Not a Steam release; not console certification.
