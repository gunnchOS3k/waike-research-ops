# Week 9: Accessible professional communication

Accessibility is part of professional communication, not a sticker. Ticket PD-2925 requires captions=true, plain_language=true, alt_text≥12 characters, color_only_signals=false, and large_print_available=true. Color-only 'red means fail' without text fails. Missing captions on desk explainer videos fails.

NO_AI week for the a11y checklist walkthrough: learners inspect a real flyer mock and mark the five fields honestly. Fabricating disabled-patron quotes is forbidden.

Consensus Ladder: observed = flyer uses red/green only; inferred = color_only_signals true (bad); still need = text labels; action = revise and resubmit. Large-print packets live in the student path. Harbor Desk Voice insists on numbered ticket IDs in journals so a Saturday volunteer can continue without a hallway interrogation. Write the next action as a verb phrase a stranger can execute. Keep patron faces, passwords, and invented harm counts out of the packet. If two tools disagree, write what you saw, then what you guessed, then the missing fact before changing shared systems. Professional development here is measured by reproducible desk artifacts, not by slogans about culture.
