# Week 10: Personal digital safety plan — the page you keep

DCO-3A10 asks each learner to leave the Library Lab with one page they will actually use. It names a password manager, because unique secrets for every site are impossible to remember otherwise. It turns on multi-factor sign-in for the email account first, since email is where every other password reset arrives, so whoever controls it controls the rest. It lists the backup copies by media and location, passes the 3-2-1 rule, and records the date of the last test restore. It names a real person or desk to show strange messages to, such as the library's IT desk, so nobody has to judge a convincing scam alone at midnight. It records which colours and font sizes work for the reader's eyes. It never contains an actual password, PIN, or recovery code; those belong in the manager or on paper locked away, not on a page that might be photographed. Mentors check the plan against six or more passed labs and ask the learner to show one step live, such as opening a file from the cloud backup.

## Worked example

password manager yes; MFA on email yes; laptop/USB/cloud backups with tested restore; report phishing to the library IT desk; no real passwords in the plan
