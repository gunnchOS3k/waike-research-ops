# lab_dco_safety_plan — Personal digital safety plan

labs_passed ≥ 6; password manager and MFA on email; a 3-2-1 backup with a tested restore; a named place to report phishing; no real passwords in the plan.

Try it, then change one number in your file and check that the answer moves:

python3 scripts/run_course_labs.py --lab lab_dco_safety_plan --submission path/to/student.json

Common miss: A plan that lists actual passwords fails immediately.
