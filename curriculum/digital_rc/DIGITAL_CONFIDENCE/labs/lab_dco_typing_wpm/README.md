# lab_dco_typing_wpm — Keyboard fluency — gross WPM, net WPM, accuracy

From characters typed, minutes, and uncorrected errors, compute gross WPM (chars/5/min), net WPM (gross − errors/min), and accuracy.

Try it, then change one number in your file and check that the answer moves:

python3 scripts/run_course_labs.py --lab lab_dco_typing_wpm --submission path/to/student.json

Common miss: Forgetting the five-characters-per-word convention fails.
