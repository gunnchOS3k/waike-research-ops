# Glossary — EMBEDDED_PROTOTYPING

- **MCU**: Microcontroller running ForgeSense subsystem firmware.
- **Flash / SRAM**: Non-volatile image store vs volatile runtime memory.
- **GPIO contract**: Pin direction, pull, and safe default before pinmux.
- **I2C / SPI**: Serial buses for sensors, displays, and flash.
- **ADC**: Analog-to-digital conversion; counts need a stated vref.
- **ISR**: Interrupt service routine — short, budgeted latency.
- **Devicetree (DT)**: Hardware description consumed by Zephyr-class firmware.
- **QEMU**: Digital board model for boot before iron.
- **PHYSICAL_PENDING**: Claim marker when EVT/solder/OTA evidence is absent.
