# Glossary — DATA DASHBOARDS

Track: `DATA_DASHBOARDS`

## normalized schema
Tables organized to reduce redundancy with clear keys.

## ETL/ELT
Extract-transform-load patterns moving data into analytics stores.

## metric definition
Named calculation with owner, grain, and filters.

## row-level privacy
Restricting which rows a viewer may see.

## freshness SLA
How old a dashboard metric may be before it is stale.

## reproducible query
Query + parameters that regenerate the same result on a fixture.

## HITL publish
Human review before publishing metrics that affect decisions.

## PII minimization
Collecting/storing only necessary personal data.
