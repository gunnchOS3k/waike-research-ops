# Accessibility notes — COMPUTER_NETWORKING / NETWORKING_INFRA

- Prefer text markers over color-only status (e.g., OVERDUE, DENY, BURST).
- Lab validators accept JSON text; GUI screenshots are not acceptance.
- Provide alt text for any topology diagrams learners draw.
- Keyboard-friendly: all graded artifacts are JSON/markdown files.
- Low-bandwidth: fixtures are small JSON; no multi-GB downloads required.
- Screen readers: week titles and lab IDs are unique and stable.
