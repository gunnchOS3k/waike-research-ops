# Glossary — Computer Networking / NETWORKING_INFRA

- **CIDR**: Prefix length that defines the network lot size (e.g., /26).
- **LPM**: Longest prefix match — more specific routes win.
- **VLAN**: Broadcast domain isolation key; MAC tables are (MAC, VLAN).
- **TTL**: Hop budget; decrement on forward; drop at 0/1 per lab rule.
- **STP**: Loop breaker — one forwarding tree per VLAN.
- **NAT**: Address rewrite at the edge; inside vs outside mapping.
- **ACL**: Ordered permit/deny; first match wins.
- **5-tuple**: src IP, dst IP, protocol, src port, dst port.
