# IT_SUPPORT_HARDWARE — Bench-lead notes, week 6

**Board work:** 3840×2160×60×24 = 11.94 Gbit/s → fits HDMI 2.0 (14.4) and DP 1.4 (25.92), not HDMI 1.4 (8.16); at 120 Hz 23.89 Gbit/s → only DP 1.4

**Hands on the case:** have each technician run lab_ish_display_link against the machine on their bench.

**Watch for:** Promising 4K 60 Hz over an HDMI 1.4 port because the cable is new.
