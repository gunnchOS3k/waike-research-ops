# IT_SUPPORT_HARDWARE — Bench-lead notes, week 5

**Board work:** T1 fans/no display/beeps → memory_or_cpu_seating; T2 dead → power_path; T3 shuts down under load → thermal_or_psu_capacity; T4 no boot device → boot_order_or_disk; T5 stop error after boot → driver_or_os

**Hands on the case:** have each technician run lab_ish_fault_isolation against the machine on their bench.

**Watch for:** Replacing the motherboard before reseating memory.
