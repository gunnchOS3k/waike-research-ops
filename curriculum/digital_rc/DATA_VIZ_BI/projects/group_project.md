# Group project — Data Viz + BI (Civic Metrics Studio)

## Brief
Create a **storyboard dashboard** answering one civic question with three charts. Roles: viz author + narrative reviewer.

## Deliverables
1. Storyboard PDF/HTML with question → charts → decision ask.
2. Encoding rationale (why not pie charts for ranks, etc.).
3. Accessibility checklist completed.
4. Provenance block with fixture ID.

## Rubric anchors
Truthfulness · Accessibility · Provenance · HITL narrative review

## Explicit non-claims
Not a Tableau/Power BI certification; not live BI ownership.
