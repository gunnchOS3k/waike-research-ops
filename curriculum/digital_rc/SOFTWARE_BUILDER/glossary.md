# Glossary — SOFTWARE BUILDER

Track: `SOFTWARE_BUILDER`

## pull request
Proposed change with review before merge.

## CI
Continuous integration — automated checks on each change.

## migration
Versioned schema change applied forward/back.

## authz
Authorization — what an identity is allowed to do.

## observability
Signals to diagnose failures in running software.

## rollback
Returning to last-known-good after a bad deploy.

## HITL review
Human code review before merge on protected paths.

## empty-fail lab
Lab harness that fails empty/wrong submissions.
