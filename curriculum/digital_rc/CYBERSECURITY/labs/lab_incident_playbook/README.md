# lab_incident_playbook — 800-61-shaped clock

detect → contain → eradicate → recover → lessons. Wipe-before-contain fails.

## Student artifact
Keys: `steps`.
An empty incident note fails no_attacker_word. targets other than course_ctf_fixture fail no_network.
A file whose entire body is `PASS` is rejected by `_fail_if_print_pass`.

## How to run
From the Harbor SOC repo root, submit fixture answers only. Do not point this lab at a host you do not own.
```
python3 scripts/run_course_labs.py --lab lab_incident_playbook --submission path/to/student.json
python3 scripts/run_course_labs.py --lab lab_incident_playbook --empty
```

Putting eradicate first fails contain_before_wipe.
