# lab_threat_model — Harbor desk threat model (defensive)

Name asset, ≥3 threats, ≥2 controls. offensive_scope must be none. No exploit steps.

## Student artifact
Keys: `asset, threats, controls, offensive_scope`.
Empty {} fails. A file whose entire body is PASS raises _fail_if_print_pass.

## How to run
```
python3 scripts/run_course_labs.py --lab lab_threat_model --submission path/to/student.json
python3 scripts/run_course_labs.py --lab lab_threat_model --empty
```

## Safety
Defensive educational lab only. No malware, no exploit PoCs, no unauthorized access.
