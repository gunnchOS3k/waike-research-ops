# Group project — AI/ML Edge (EdgeForge Bench)

## Brief
In pairs, ship a **reproducible edge inference packet** for one named civic use case (e.g., desk camera occupancy counter). One learner owns the model/fixture path; the other owns evaluation + claim boundary.

## Deliverables
1. `model_card.md` — intended use, out-of-scope uses, evaluation golden-set ID, latency budget.
2. Lab JSON from `lab_edge_infer` (or course lab equivalent) with seed, device class, digest.
3. Drift note: what distribution shift would invalidate the packet.
4. 3-minute demo script; no PII, no invented field accuracy.

## Rubric anchors
- Reproducibility (digest + seed) · Claim honesty · HITL disclosure · Accessibility (keyboard/offline notes)

## Explicit non-claims
Does not grant ML certs, does not prove pier deployment, does not invent MEASURED_FIELD captures.
