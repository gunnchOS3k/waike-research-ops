# Glossary — AI ML EDGE

Track: `AI_ML_EDGE`

## edge inference
Running a trained model on-device or near-device rather than only in a central cloud.

## feature store
Catalog of reusable input signals with owners, freshness, and lineage.

## drift
Shift in input or label distribution that can invalidate a previously validated model.

## quantization
Reducing numeric precision of weights/activations to shrink models for edge hardware.

## latency budget
Maximum allowed end-to-end inference time for a named use case.

## golden set
Fixed evaluation examples used to catch silent quality regressions.

## HITL review
Human-in-the-loop gate before a model output is treated as operational truth.

## synthetic fixture
Labeled fake data used for labs; never relabeled as field measurement.
