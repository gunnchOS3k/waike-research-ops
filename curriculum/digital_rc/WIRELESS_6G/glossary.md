# Glossary — WIRELESS 6G

Track: `WIRELESS_6G`

## NR
5G New Radio air interface family.

## NTN
Non-terrestrial network (satellite/HAPS) scenarios.

## beamforming
Directional transmission/reception using antenna arrays.

## KPI window
Time-bounded set of radio performance indicators.

## link budget
Accounting of gains/losses along a radio path.

## spectrum license
Regulatory permission to transmit in a band.

## HITL TX
Human authorization before any transmit on physical radios.

## SIMULATED RF
Fixture KPIs; not authorization to radiate.
