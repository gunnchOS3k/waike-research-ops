# Reproducibility

## Minimum bar for digital credit
- Independent second run matches baseline digest (week 9 handoff lab).
- Capstone includes environment, fixture path, method, digests, limitations.
- Seeds and SNR/MCS settings recorded for controlled sims.
- Empty `{}` and print-only PASS submissions fail harnesses.

## Artifact checklist
- [ ] Commands + cwd
- [ ] Runtime versions
- [ ] Fixture ID / path (`fixtures/sgc_baseline/` etc.)
- [ ] SHA-256 digests (64 hex)
- [ ] evidence_class labels
- [ ] claim audit lists
- [ ] UNAVAILABLE siblings listed without fake SHAs
