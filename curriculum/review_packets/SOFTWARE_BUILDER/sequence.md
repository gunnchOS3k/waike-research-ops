```
# Software Builder — ForgeDesk to Device Lab Deploy
## Who this is for
Ten weeks on ForgeDesk: git conflict, REST, migrations, accessible UI, authz, tests, GitHub Actions, deploy/rollback, security review, observability. Capstone is issue→deployed local/Device-Lab artifact. CS50/CS50 Web and Actions docs are structure citations only. No dumps.
## Tracks and academy
- Tracks: SOFTWARE_BUILDER
- Academy: ACADEMY_SOFTWARE
## Duration
Ten ForgeDesk weeks (~8–10 hours/week including CI red-build time). Not a two-hour HTML workshop. Device Lab compose is scheduled; do not deploy ungated on pull_request.
## Weekly map
- Week 01: ForgeDesk ticket 8801 — git conflict on the deploy branch
- Week 02: REST for checkout — status codes that mean something
- Week 03: Migrations that do not strand the Device Lab
- Week 04: Frontend contract — accessible checkout board
- Week 05: Authz matrix — desk vs reader vs forge-bot
- Week 06: Automated tests that catch the silent 200
- Week 07: GitHub Actions — CI that blocks bad merges
- Week 08: Deploy and rollback on Device Lab compose
- Week 09: Security review — findings with severity bands
- Week 10: Observability and issue→deploy capstone
## Assessments
ForgeDesk assessment mix: weekly builder quizzes on ticket 8801-class numbers, a mid-course audit (20 original items on conflict/REST/migrate/authz/CI), a final (24 original items on deploy/security/SLO/capstone path), a practical over ten runnable labs that reject empty/wrong/print-PASS, and an issue-to-deploy group project. Silent 200 on forbidden writes scores zero.
## Claim boundary
Aligns to CS50/CS50 Web topic shape and GitHub Actions docs as PUBLIC_REFERENCE_ONLY. Secure-dev themes are labels. Does not grant vendor certs. Instructor keys stay out of the learner packet.
## Kinesthetic hook
Merge a real conflict, ship a checkout API, and pin a digest on local Device Lab compose.
```
