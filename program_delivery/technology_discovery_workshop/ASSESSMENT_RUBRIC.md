# Independent workshop-task observation rubric

Use a fresh case after instruction. This is a subset workshop observation, not the canonical full-course mastery decision. The existing Digital Confidence Hub rubric remains authoritative for its independent assignment. No real learner has been assessed by producing this packet.

For each criterion record exactly one state: **not_observed**, **needs_revision**, or **observed**. Record access assistance separately; do not penalize assistive technology. If a helper supplied the technical answer, schedule a fresh independent explanation rather than marking independent performance observed.

| Criterion | Evidence needed for observed | Useful revision response |
|---|---|---|
| files | Learner locates an owned folder, renames a working copy and reopens its unchanged fictional contents; selected-byte check matches | Compare actual location/name/extension; reopen the copy, preserve the original |
| restore | Learner identifies preserved source, changed working copy and separate restored destination, then verifies original bytes | Explain which file is the source; restore to an empty destination and compare |
| privacy | Learner uses fictional data, excludes credentials/identifiers and distinguishes observed facts from guesses | Remove private data; rewrite the observation and a permitted next test |
| capacity | New case arithmetic, units and policy conclusion are correct and explained, including a possible below-policy result | Subtract used/separate reserve once; explain denominator and units; retry changed values |
| explanation | Original method, failure/recovery, limitation and safe next action can be explained and demonstrated | Name the unknown, reproduce a controlled error and explain recovery with new inputs |

Observation metadata: workshop version, curriculum revision, actual session dates, anonymous participant code, reviewer identity/authority recorded privately, state per criterion and agreed remediation. A public report should use aggregate counts only under the buyer's agreed policy. The supplied CSV utility uses an explicit reviewer attestation and anonymous codes; it does not authenticate people or independently verify their declarations.

All five observed states support “instructor reported the workshop-task criteria observed”, subject to authentic reviewer verification. They do not support certification, employability, full-course completion or a general efficacy claim. Pending/failed criteria must remain visible. A learner can revise and be observed again; preserve attempt context under the buyer's approved record process.
